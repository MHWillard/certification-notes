ASPECTS OF CLOUD MIGRATION
moving on-prem data/apps/resources to cloud

tpes of migrations?
-on-prem to cloud
-cloud to on-prem
-cloud to cloud

Steps for cloud-to-cloud?
-make identity and access management IDs and permissions
-set up VPN connection
-configure network access requirements
-make cloud extensions
-install migration packages for VMs
-test migration
-migrate in groups and test

Phases of cloud migration?
-assessment and discovery for current systems, planning, implementation, optimize cost/performance/security

Types of virtualization migrations?
-physical to virtual P2V
-virtual to physical V2P
-Virtual to virtual V2V

Migration phases?
-assessment, planning, deployment, optimize

General steps for VM migration tools?
-save physical server config/data as snapshot
-allocate resoutces to VM
-use tool to load snapshot into VM

** very important part, very testable so know this**
Cloud migration strategies?
-rehosting (no modification needed, take it to cloud)
-replatforming (modify the app but not externsive redvelopment)
-repurchasing (drop old app and replace with modern cloud ready app)
-retiring (drop app, don't replace it)
-refactoring (restructure/optimize existing app)
-retaining (keep app as on-prem traditional deployment)
-rearchitect: revise whole architecture to be cloud ready
-hybrid: mix of the above

MIGRATION CONSIDERATIONS

Whato to consider for cloud migration?
-platform compatbility-resources, storage and speed, security
-cost: on demand vs. spot instances, scaling options
-service availability: how many regions where it's available, uptime, redundancy
-vendor lock-in: how is cost in money/time, planning needed to diversify and plan for future
-compute: compontents and performance, migration, scaling, billing
-storage: how fast and expensive it is to trasfer, how fast, type of storage, how integrity it is
-networking: bandwidth, security, access control, IP addressing, security controls
-mamnagement: amount of overhead, regulations, compliance, monitoring performance, monitoring cost, security

Instance types for cost?
-spot: bid on unused cloud capacity
-dedicated: reserve physical hardware for needs
-on-demand: flexible but more expensive than spot
-reserved: long-term commitment for cost saviings
